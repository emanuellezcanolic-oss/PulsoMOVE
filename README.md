# PulsoMOVE

App web para que el equipo de recepción de The Move Club vea y registre sus tareas del día.

- `web/`: la app (HTML, CSS y JS), publicada en GitHub Pages.
- `apps-script/`: el backend, una Google Apps Script Web App que guarda todo en una planilla privada.
- `tests/`: pruebas del backend con Node (`npm test`).

Este repositorio es público: no contiene datos de socios, datos del equipo ni claves.
Las claves viven solo en las Propiedades del script y en la computadora que carga las tareas.
